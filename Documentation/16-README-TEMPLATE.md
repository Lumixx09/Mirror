# MIRROR

**The Differential Testing Laboratory for the Internet**

MIRROR runs controlled browser experiments to discover, reproduce and
explain differences in the experiences websites deliver under different
browsing conditions.

## What it does

-   Runs isolated browser sessions
-   Replays equivalent user journeys
-   Captures page, interaction and network observations
-   Compares DOM, text, commercial values and behaviour
-   Produces evidence-linked findings
-   Preserves artifacts and reproducible reports
-   Uses AI as an optional investigation assistant
